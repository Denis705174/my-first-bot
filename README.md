# 🤖 Telegram-бот для сбора заявок

Автоматический бот, который собирает заявки от клиентов и отправляет их в Excel + на email.

## ✨ Что умеет

- 📋 **Сбор заявок** — 3 вопроса клиенту (Имя, Телефон, Услуга)
- 💾 **Сохранение в Excel** — все заявки в таблице `Заявки.xlsx`
- 📧 **Email-уведомления** — мгновенная отправка на почту
- ⌨️ **Кнопки** — удобное меню в Telegram
- ❌ **Отмена** — можно прервать заполнение

## 🎯 Вариант B: Первые клиенты и первые деньги

Сейчас у тебя есть продукт, который решает реальную проблему: малому бизнесу не нужно сидеть в телефоне и отвечать каждому, кто хочет записаться.

### Где искать первых клиентов

| Где | Как |
|---|---|
| **Свои знакомые** | Напиши 3-5 людям, которые делают услуги (маникюр, репетиторство, фото, ремонт, доставка) |
| **Авито / Юла** | Найди объявления малого бизнеса, напиши предложение |
| **Местные чаты** | В Telegram/VK чаты «Услуги [твой город]», «Работа» |
| **Instagram** | Найди мастеров с небольшим числом подписчиков — им нужна помощь |
